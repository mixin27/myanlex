## 0.1.0-beta.0

- Prepare the first public beta of the HTTP SDK with all nine language and batch
  operations, plus a health check.
- Provide typed results and errors, per-item batch failures, and Unicode
  code-point offsets.
- Support explicit conversion directions with optional source validation, caller
  cancellation, request deadlines, and explicit HTTP-client ownership.
- Preserve API quota and rate-limit error details without automatic retries or
  local-engine fallback.
- Add repository and issue-tracker metadata, beta installation instructions, and
  API availability and security guidance.
- Require Dart 3.13.1 or newer within Dart 3. This beta is not a stable-contract
  or independent linguistic-accuracy guarantee.

## 0.0.0

- Initial unpublished SDK: nine language/batch methods, typed models and errors,
  timeouts, cancellation, and explicit HTTP-client ownership.
