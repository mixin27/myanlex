# Security policy

See the
[API hardening baseline and remaining release gates](docs/security/hardening.md)
for operational protections and deployment requirements.

MyanLex is in early development and does not yet have supported release
branches.

Please do not open a public issue for a suspected security vulnerability.
Contact the maintainers privately through the security-reporting mechanism on
the repository host. A dedicated security email will be published before the
first public release.

Include a description, reproduction steps, affected versions or commits, and the
potential impact. Maintainers will acknowledge a report as soon as practical and
coordinate disclosure after a fix is available.
