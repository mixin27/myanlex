MyanLex provides HTTP operations for Myanmar text. You can call an available
deployment from any language: you do not need the platform repository, NestJS,
Prisma or a local database to use its API.

## Explicit processing

Detection does not convert. Conversion does not silently normalize.
Syllabification is not dictionary word segmentation, and transliteration is not
translation. Each operation reports a versioned profile and preserves or
diagnoses unsupported input rather than guessing its meaning.

All spans use [Unicode code-point offsets](/docs/language/offsets).
