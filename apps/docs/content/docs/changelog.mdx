## Unreleased

- Versioned language operations, batch processing and Unicode code-point spans.
- Self-hosted account sessions, optional Google/GitHub login and dynamic roles.
- Organizations, projects, scoped keys and best-effort usage reporting.
- Distributed burst limits and optional organization-wide monthly quotas.
- TypeScript and Dart HTTP clients.
- Dedicated searchable MDX documentation with generated API reference.

Security/operational hardening and independent linguistic review remain release
gates. No paid billing flow, offline Dart engine or measured real-world accuracy
claim is included.
