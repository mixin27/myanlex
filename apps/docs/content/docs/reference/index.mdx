The pages in this section are generated directly from the checked-in OpenAPI
schema. [Download OpenAPI JSON](/openapi.json) to use with your own tooling.

Choose an operation in the sidebar to inspect authentication, request
parameters, response schemas and code samples. Example server addresses describe
the intended deployment contract, not proof that a public service is currently
available.

This site intentionally does not collect keys or execute requests. Test calls in
your deployment's Scalar reference. Platform operations require a verified
console session; language operations use a project API key. See
[Authentication](/docs/authentication).
